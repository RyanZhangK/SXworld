# 深巷世界

> 在机械轰鸣与魔法低语之间，在星空与深渊之间，寻找属于你的那条深巷。

**Minecraft 1.20.1 · Forge 47.4.18 · 当前版本 1.1.1**

---

## 这是什么？

**深巷世界**是一个以 **Create 机械动力**为核心的综合型整合包，融合了工业科技、现代战术、奇幻冒险、修仙玄学与星际探索五条主线。超过 **150 个精选 Mod**，从齿轮传动到核能发电，从巫术结界到枪械改造，从深海地牢到外太空殖民——你可以选择任意一条路深入，也可以将它们全部打通。

整合包追求**有深度的玩法**，而非简单的内容堆砌：每一个系统都有其完整的资源链与进阶路径，不同系统之间存在真实的联动空间，等待玩家自己去发现。

---

## 核心玩法

### ⚙️ 机械工业（Create 生态）
以 Create 机械动力为骨架，搭配电力扩展、附魔工业、柴油发电机、工厂物流等模组，构建从水车到核电站的完整工业体系。超级管道（Hypertube）连接你的每一处工厂，大炮（Create Big Cannons）守卫你的领地。

### 🔫 现代战术
TACZ（Timeless and Classics Zero）带来高还原度的现代枪械系统，支持枪械改装与弹道模拟。战术装备（LR-Tactical）提供完整的战术配件，配合语音聊天（Simple Voice Chat），多人作战体验媲美专业射击游戏。

### 🧙 奇幻与修仙
Goety 巫术系统让你召唤亡灵、施展诅咒；长生诀（ChangShengJue）开启一套完整的修仙境界与功法体系。两套魔法系统风格迥异，各有其独特的成长路线。

### 🚀 航空与星际
Ad Astra 带你突破大气层，在月球、火星乃至更远的星球建立殖民基地。沉浸式飞机（Immersive Aircraft）、帆船（Small Ships）与各类载具让旅途不再单调。

### ⚡ 电力与核能
Electrodynamics + Nuclear Science + Power Grid 构成完整的电力网络体系，从太阳能电池板到核裂变反应堆，为你的工业帝国提供源源不断的能量。

### 🍖 生活与烹饪
Farmer's Delight 及其大量扩展（每壶热锅、葡萄酒庄、玉米美食……）构建了丰富的食物系统。Create 中央厨房让你用机械自动化烹饪流程，酿酒厂与餐厅不再是梦。

## 快速开始

### 使用 Modrinth App（推荐）
1. 安装 [Modrinth App](https://modrinth.com/app)
2. 从 [Releases](../../releases) 下载最新的 `.mrpack` 文件
3. 在 Modrinth App 中点击「导入」，选择下载的文件
4. 启动游戏

### 使用 Prism Launcher
1. 安装 [Prism Launcher](https://prismlauncher.org/)
2. 新建实例 → 从文件导入 → 选择 `.mrpack` 文件
